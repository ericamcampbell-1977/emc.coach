# The Evolution Lab Collective — emc.coach

Static website hosted on GitHub Pages. No build step: plain HTML, CSS, and JS.

## Files
- `index.html` — the homepage (all content lives here)
- `styles.css` — colors, fonts, layout (colors are at the top in `:root`)
- `script.js` — mobile menu + footer year
- `404.html` — page-not-found
- `favicon.svg` — browser tab icon
- `CNAME` — tells GitHub Pages the custom domain (`emc.coach`)
- `.nojekyll` — serve files as-is
- `images/` — add your headshot here as `erica.jpg`
